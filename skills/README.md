# Skills: Nuru from any harness, through Sippar

These are agent skills (a `SKILL.md` with frontmatter each). Give your agent the folder, or read
them yourself; they say the same thing either way. They describe one door,
`https://sippar.network/mcp/protocol/pay`, an MCP server ChatGPT, Claude, Hermes Agent and any
other MCP host can add, and the same products reached over plain HTTP with x402 for an agent that
holds its own wallet.

Sippar connects an agent to the data and services it trusts and settles each call on chain.
The agent's model is yours: ChatGPT's, Claude's, or NVIDIA Nemotron on Nebius Token Factory, as in
this repository's own runtime and inside Hermes Agent under NVIDIA NemoClaw on a Nebius AI Cloud VM.
Prices are not written here: the shelf is live, and `list_products` or the free catalog carries
each product's price at the moment you ask.

Every response from the door names its source. What you make of the data is yours; Sippar
passes it through as the provider returns it.
